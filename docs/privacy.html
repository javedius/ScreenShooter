Privacy policy

Simple by design.

Last updated: August 12, 2026

ScreenShooter does not collect, store, sell, or transmit personal information. Screenshot processing happens locally in your browser.

Information we collect

ScreenShooter does not collect analytics, browsing history, page content, screenshots, account details, or personal information.

How permissions are used

The extension accesses the active tab only when you start a capture. It uses this access to capture visible page content, scroll a page, select an element, and temporarily hide visual elements that interfere with a clean screenshot. Download access is used only to save the PNG or PDF file you requested.

Data storage and transmission

Generated screenshots remain on your device and are saved to your Downloads folder. ScreenShooter does not send screenshot data to a remote server. Your selected export format may be stored locally in the browser so it can be remembered the next time you open the extension.

Third parties

ScreenShooter does not use third-party analytics, advertising networks, tracking technologies, or external processing services.

Changes

If the extension’s data practices change, this policy will be updated before the new behavior is released.

Contact

Questions and issues can be submitted through the ScreenShooter GitHub repository.
